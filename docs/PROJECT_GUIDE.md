# 项目技术指南

## 1. 模块说明

| 文件 | 职责 |
|---|---|
| `STM32/User/main.c` | 初始化、急停/复位、阈值联动、遥测 |
| `STM32/Hardware/Encoder.c` | 编码器接口与计数读取 |
| `STM32/System/Timer.c` | TIM2 周期中断时基 |
| `STM32/Hardware/adc.c` | PA0 ADC 与角度换算 |
| `STM32/Hardware/usart.c` | USART1 初始化和发送 |
| `STM32/Hardware/Key.c` | PB0/PB1 输入 |

## 2. 执行流程

1. 初始化 LED、OLED、定时器、编码器、电机、继电器、按键、ADC 和 USART；
2. TIM2 中断读取编码器增量并更新 `Speed`；
3. 主循环检查 PB0 急停和 PB1 复位；
4. 运行允许时读取角度、刷新 OLED；
5. 通过 USART1 发送速度和角度；
6. 根据速度和角度阈值切换电机与继电器。

## 3. 联调顺序

1. 不接电机，验证 OLED 和 USART；
2. 旋转编码器，确认速度正负和数值变化；
3. 转动电位器，确认角度范围；
4. 验证 PB0 能立即禁止系统；
5. 验证 PB1 只恢复运行许可，不应绕过阈值；
6. 最后接入低压电机和驱动板。

## 4. 常见问题

| 现象 | 排查 |
|---|---|
| 速度恒为 0 | 编码器 A/B 相、TIM3 配置、共地 |
| 角度不变 | PA0 模拟电压、ADC 参考电压、换算范围 |
| 电机方向相反 | PA3/PA4 接线和电机极性 |
| 急停无效 | PB0 上拉、按键低电平、接地 |
| 串口乱码 | USART1 波特率和 8N1 参数 |
| 继电器逻辑相反 | 模块高/低电平触发方式 |

## 5. 工程化改进

- 使用 PWM 命令而不是测量速度直接控制电机；
- 增加速度 PID 与独立目标速度；
- 急停采用硬件切断和软件锁存双通道；
- 增加传感器断线、超量程和通信超时诊断；
- 为遥测增加时间戳、帧头、长度和校验；
- 标定 ADC 值到真实角度的映射。
